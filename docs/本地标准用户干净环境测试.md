# 方案 A：本地标准用户干净环境测试

> 适用：当前机器 Windows 11/10 Home，无法使用 Windows Sandbox/Hyper-V，
> 也不想装 VirtualBox/VMware 时，用“新建标准本地用户”模拟普通用户安装。
>
> 目标：验证安装包在**无 Python、无开发环境、非管理员、全新用户配置**下可用。
>
> 局限：不是全新 Windows，系统级运行库/驱动仍共享；要测 OS 级干净环境，
> 用 [`docs/VirtualBox干净环境测试.md`](VirtualBox干净环境测试.md)。

---

## 1. 构建安装包

### 1.1 构建 exe / 便携包

```bash
py -3.13 -m pip install pyinstaller
py -3.13 tools/build_windows.py
```

确认：

```text
dist/wows_coyote/wows_coyote.exe
dist/wows_coyote/_internal/...
releases/wows_coyote-1.0.0-gpl.zip
releases/wows_coyote-1.0.0-win64.zip
```

### 1.2 编译 Inno Setup 安装包

```powershell
winget install --id JRSoftware.InnoSetup -e
```

```bat
cd /d <项目目录>
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\wows_coyote.iss
```

输出：

```text
dist_installer\wows_coyote-1.0.0-setup.exe
```

中文语言文件已随仓库提供：`installer/ChineseSimplified.isl`。

> 本机未安装 Inno Setup 时，先装再编译；不需要把语言文件复制到 Inno 安装目录。

---

## 2. 创建标准测试用户

管理员 PowerShell：

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File tools\create_clean_test_user.ps1
```

脚本会：

- 创建本地用户 `wows_clean`；
- 默认是标准用户，不加入 Administrators；
- 生成临时密码并打印；
- 不创建任何开发环境。

手动等价命令：

```powershell
net user wows_clean "<自定义临时密码>" /add
net localgroup Users wows_clean /add
```

然后**注销当前用户**，用 `wows_clean` 登录。

---

## 3. 确认是干净用户

在该用户 PowerShell：

```powershell
whoami
echo $env:LOCALAPPDATA
Get-Command python,py -ErrorAction SilentlyContinue
Test-Path "$env:LOCALAPPDATA\wows_coyote\settings.json"
```

预期：

- `%LOCALAPPDATA%` 是 `C:\Users\wows_clean\AppData\Local`；
- 看不到开发机用户目录下的 Python；
- `settings.json` 不存在（首次启动）；
- 没有旧的 `%LOCALAPPDATA%\wows_coyote` 目录。

### 严格证明不依赖 Python

WindowsApps 可能有 `python.exe` 商店别名，或机器级 msys64 Python；它们不代表 exe 依赖 Python。
用最小 PATH 启动：

```powershell
$env:PATH = "$env:SystemRoot\system32;$env:SystemRoot"
& "$env:LOCALAPPDATA\Programs\wows_coyote\wows_coyote.exe" --no-ui --no-telemetry --port 0
```

能起来就说明运行时不依赖 Python。测试完按 Ctrl+C。

## 4. 安装

把安装包复制到测试用户桌面，或直接从项目的 `dist_installer\` 目录运行：

```text
wows_coyote-1.0.0-setup.exe
```

检查：

- 不弹 UAC（`PrivilegesRequired=lowest`）；
- 中文安装向导可选；
- 许可页显示 GPL-3.0；
- 安装到：
  ```text
  C:\Users\wows_clean\AppData\Local\Programs\wows_coyote
  ```
- 安装目录包含：
  ```text
  LICENSE
  THIRD_PARTY.md
  SOURCE_OFFER.md
  CHANGELOG.md
  source\wows_coyote-1.0.0-gpl.zip
  wows_coyote.exe
  _internal\...
  ```

---

## 5. 首次启动

从开始菜单/桌面快捷方式启动。

- 直接进入主控制台（不再有 `/setup` 向导）；
- 每次启动在设置页扫码配对；设置页「遥测文件」指定路径；
- 主控制台底部「安全使用」可展开；强度上限以 App/设备通道上限为准；
- 手机与电脑同一局域网；
- App 使用「Socket 控制」扫码；
- 如果电脑多网卡，设置页/启动参数可用 `--advertise-ip` 指定手机可达的 IP。

检查文件：

```text
C:\Users\wows_clean\AppData\Local\wows_coyote\settings.json
C:\Users\wows_clean\AppData\Local\wows_coyote\qr.svg
```

### 防火墙

首次运行可能弹 Windows 防火墙，选“专用网络”。

标准用户可能无法点“允许”；管理员先加规则：

```powershell
New-NetFirewallRule -DisplayName "wows_coyote" `
  -Direction Inbound -Action Allow -Profile Private `
  -Program "C:\Users\wows_clean\AppData\Local\Programs\wows_coyote\wows_coyote.exe"
```

## 6. 功能验收

- [ ] 无 UAC 安装；
- [ ] 中文安装向导/许可页；
- [ ] 首次启动直接进入主控制台（无 `/setup`）；
- [ ] 设置页指定遥测路径；每次启动重新扫码配对；
- [ ] 扫码连接、App 上限显示；
- [ ] A/B 强度、模板、clear、loop；
- [ ] F12 全局急停；
- [ ] 关闭主窗口归零退出；控制台/设置/事件标签切换不归零；关闭悬浮窗只关窗口、不归零；
- [ ] 设置页改遥测路径/事件参数后重启仍保留；
- [ ] 设置页/overlay 正常；
- [ ] 卸载后程序目录删除，`%LOCALAPPDATA%\wows_coyote` 保留（可手动清理）。

---

## 7. 卸载与清理

设置 → 应用 → 已安装的应用 → `wows_coyote` → 卸载。

注销测试用户，回到管理员 PowerShell：

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File tools\remove_clean_test_user.ps1
```

这会删除 `wows_clean` 用户和 `C:\Users\wows_clean` 配置目录。

---

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 安装时提示 Source 文件不存在 | 先运行 `tools/build_windows.py` |
| Inno 找不到中文语言文件 | 确认 `installer/ChineseSimplified.isl` 存在；.iss 引用的是本地文件 |
| 测试用户 `where python` 有结果 | 可能是 WindowsApps 商店别名/机器级 msys64；用最小 PATH 启动 exe 验证 |
| 手机连不上 | 同一局域网、访客隔离、防火墙、`--advertise-ip` |
| 标准用户不能放行防火墙 | 管理员先建入站规则，再切回测试用户 |
| 卸载后设置还在 | 有意的；删除 `%LOCALAPPDATA%\wows_coyote` 彻底清理 |
| 想测全新 Windows | 用 [`docs/VirtualBox干净环境测试.md`](VirtualBox干净环境测试.md) |
