# wows_coyote 初次使用完整流程

> 适用版本：`wows_coyote` 0.1.1（standalone）
> 适用系统：Windows 10 / 11 x64
> 最后更新：2026-11-21
>
> 本文从零开始，覆盖：安装前置 Mod → 验证遥测 → 安装 wows_coyote →
> 配置遥测/设备 → 扫码 → 第一次低强度测试 → 更新与排障。
>
> standalone **不需要 DGHub**；DGHub 插件是另一条独立链路，不要同时向
> 同一台设备输出。

---

## 0. 一页流程

```text
安装 ExportShipStatus Mod
  → 进训练房，确认 profile\wows_telemetry.jsonl 有数据
    → 安装 wows_coyote 0.1.1
      → 设置页选择遥测文件
        → 选择 V4 Relay（推荐）或 V3 Socket
          → 手机 App 扫码
            → App 内把 A/B 通道上限调低（如 20–40）
              → 训练房低强度测试
                → F12 急停 / 关闭主窗口归零
```

## 1. 准备清单

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 游戏 | 《战舰世界》PC 版（Steam / Wargaming Game Center 均可） |
| 前置 Mod | [ExportShipStatus-Mod](https://github.com/Not-ANumber/ExportShipStatus-Mod) v1.0.0 或更新 |
| 控制程序 | [wows_coyote 0.1.1](https://github.com/Not-ANumber/wows_coyote/releases/latest) |
| 设备 | DG-LAB 郊狼设备 + 对应 App |
| 网络 | V4 官方 Relay：能上互联网；V3 Socket：手机和电脑同一局域网 |
| 可选 | WebView2 Runtime（Win10/11 通常已自带）、OBS |

App 与连接方式的对应关系：

| 连接方式 | 使用哪个 App | 说明 |
|---|---|---|
| V4 Relay（默认，推荐） | **DG-LAB 4 App**（4.x） | 官方 Relay 不要求同一局域网 |
| V3 Socket | **郊狼 App** | 手机和电脑必须同一局域网 |

## 2. 安装前置 Mod：ExportShipStatus

wows_coyote **不直接读取游戏内存**，它读取 ExportShipStatus 写出的
`profile\wows_telemetry.jsonl`。没有这个 Mod，程序不会有任何游戏数据。

### 2.1 下载

打开 Mod 的 Releases 页面：

**https://github.com/Not-ANumber/ExportShipStatus-Mod/releases**

下载最新版资产：

```text
ExportShipStatus-dist.zip
```

把它解压到一个普通文件夹（不要在压缩包里直接双击运行）。

### 2.2 安装

先关闭游戏。然后双击解压目录里的：

```text
install.bat
```

安装脚本会自动：

1. 探测游戏路径（注册表 → Steam 多库 → 常见路径）；
2. 如果找到多个游戏安装，给出菜单让你选；
3. 定位最新的 `bin\<版本>` 目录；
4. 把模组安装到：

```text
<游戏根>\bin\<版本>\res_mods\PnFMods\ExportShipStatus
```

5. 确保共享加载开关 `res_mods\PnFModsLoader.py` 存在。

如果自动探测失败，或想显式指定游戏目录：

```bat
install.bat "D:\Games\World_of_Warships"
```

把路径换成你的实际游戏根目录（里面有 `bin`、`profile` 的那一层）。

如果提示 `res_mods` 没有写入权限，右键 `install.bat` →
“以管理员身份运行”。

安装完成后**重启游戏客户端**。

### 2.3 验证 Mod 已加载

打开：

```text
<游戏根>\profile\python.log
```

搜索：

```text
[ExportShipStatus] Created instance
```

看到这一行说明模组已被 PnFMods 加载。

### 2.4 验证遥测文件

1. 启动游戏，进入一局**训练房**（不用打随机战）；
2. 进入战斗后，确认这个文件存在并且大小在变化：

```text
<游戏根>\profile\wows_telemetry.jsonl
```

3. 退出战斗后文件会被清空，这是 Mod 的正常行为：文件只保留最近一场。

如果文件存在但一直为空，请看第 9 节“遥测文件没有数据”。

### 2.5 游戏更新后必须重装 Mod

《战舰世界》每次大版本更新会新建 `bin\<新版本>` 目录，新目录里的
`res_mods` 是空的。更新后请重新运行一次 `install.bat`，否则 Mod 不会加载。

建议把 Mod 安装目录保留着，之后每次游戏大更新后重跑一次即可。

### 2.6 卸载 Mod

```bat
uninstall.bat
:: 或
uninstall.bat "D:\Games\World_of_Warships"
```

`PnFModsLoader.py` 是所有 PnFMods 模组共享的加载开关，卸载脚本会保留它。

### 2.7 合规说明

Mod 仓库说明：它只读取并导出**你自己舰船**、原版界面可见的信息，
不含敌人数据、不做自动化输入、不修改游戏可执行文件或游戏资源；
仓库同时说明该模组已通过官方模组审核。

第三方模组政策可能变化，是否允许以 WG 当前政策和赛事规则为准；
不要在禁止第三方模组的比赛/活动中使用。

## 3. 安装 wows_coyote

### 3.1 下载

打开：

**https://github.com/Not-ANumber/wows_coyote/releases/latest**

下载安装包（推荐）：

```text
wows_coyote-0.1.1-setup.exe
```

其他发布物：

| 文件 | 用途 |
|---|---|
| `wows_coyote-0.1.1-setup.exe` | Windows x64 安装包（推荐） |
| `wows_coyote-0.1.1-setup.exe.sha256` | 安装包校验值 |
| `wows_coyote-0.1.1-win64.zip` | 免安装便携版 |
| `wows_coyote-0.1.1-gpl.zip` | GPL-3.0 对应源码 |
| `SHA256SUMS.txt` | 汇总校验值 |

### 3.2 校验安装包

PowerShell：

```powershell
Get-FileHash .\wows_coyote-0.1.1-setup.exe -Algorithm SHA256
```

把结果和发布页的 `.sha256` 资产对比，一致再安装。

### 3.3 运行安装程序

双击 `wows_coyote-0.1.1-setup.exe`：

- 默认安装到 `%LOCALAPPDATA%\Programs\wows_coyote`；
- **不需要管理员权限**；
- 安装包未做代码签名，SmartScreen 可能提示；
  确认 SHA256 一致后可选“更多信息 → 仍要运行”。

窗口模式依赖 WebView2 Runtime（Win10/11 通常已自带）。
如果主窗口打不开，安装
[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
或改用 `--browser` 启动。

### 3.4 便携版（可选）

下载 `wows_coyote-0.1.1-win64.zip`，解压后直接运行：

```text
wows_coyote.exe
```

便携版不需要 Python，也不写入安装目录，但设置仍保存在
`%LOCALAPPDATA%\wows_coyote\`。

### 3.5 不要在主程序输出时安装更新

升级前先关闭主窗口：程序会 clear 双通道并把强度归零。
不要在主程序仍在输出时直接运行安装包。

## 4. 首次启动

双击开始菜单/桌面的 `wows_coyote` 快捷方式。

主窗口有三个标签：

- **控制台**：A/B 强度、战局状态、当前效果、事件流、急停；
- **设置**：设备/QR、遥测文件、输出窗口/OBS、更新；
- **事件**：基础/受击/起火/进水/死亡五类事件参数。

第一次启动不会弹向导，直接进入控制台。没有数据时按提示去“设置”页。

设置页需要确认四件事：

1. **遥测文件**：选中 Mod 写出的 `wows_telemetry.jsonl`；
2. **设备/连接方式**：V4 Relay（默认）或 V3 Socket；
3. **输出窗口**：可选 OBS/悬浮窗；
4. **更新**：0.1.1 起可检查更新。

修改后点“保存设置”；设备卡改连接方式时点“保存并刷新”，二维码会刷新。

---

## 5. 配置遥测文件

设置页 → “遥测文件” → “浏览 …”：

可以选三种路径，程序都会解析到同一个文件：

| 选择 | 示例 |
|---|---|
| 完整文件 | `<游戏根>\profile\wows_telemetry.jsonl` |
| `profile` 目录 | `<游戏根>\profile` |
| 游戏根目录 | `<游戏根>` |

自动查找始终开启；路径留空或无效时程序会自己查找并回填。

注意：

- 文件只在对局中存在；退出对局后会被 Mod 清空；
- 如果现在没有文件，直接选 `profile` 目录或游戏根目录即可，
  进战斗后程序会自动读取；
- 控制台显示血量/战局状态，说明遥测已经接通；
- 显示“等待文件”时，先确认 Mod 已加载、路径正确、已经进战斗。

## 6. 连接设备

### 6.1 选择连接方式

设置页 → “设备” → “连接方式”：

| 选项 | 适用 |
|---|---|
| **V4 Relay（DG-LAB 4）** | 默认，推荐；用 DG-LAB 4 App + 官方 Relay |
| **V3 Socket（郊狼 App）** | 用郊狼 App；手机和电脑需同一局域网 |

改完点“保存并刷新”。切换连接方式会断开当前 App，需要重新扫码。

### 6.2 V4 Relay（推荐）

1. 打开设备，进入 DG-LAB 4 App，先让 App 连上设备；
2. 电脑上 wows_coyote → 设置 → 连接方式选 **V4 Relay**；
3. Relay 选 **官方（official）**；
4. 点“保存并刷新”，页面上出现二维码；
5. 手机 App → **Socket 控制** → 扫码；
6. 扫码后在 App 里选中郊狼设备；
7. 设置页会显示“App 通道上限 A/B”。

官方 Relay 要求手机能上网，**不要求**手机和电脑在同一局域网。

如果官方 Relay 连不上，可以在 Relay 里选“本机中继（local）”，
此时手机和电脑必须在同一局域网。

### 6.3 V3 Socket

1. 手机和电脑连同一个 Wi-Fi/局域网；
2. 设置 → 连接方式选 **V3 Socket**；
3. 点“保存并刷新”；
4. 手机郊狼 App → **Socket 控制** → 扫码；
5. Windows 防火墙弹窗时允许“专用网络”；
6. 配对成功后设置页显示 App 上报的通道上限。

如果二维码地址是 `127.0.0.1` 或手机打不开，常见原因是多网卡/VPN/虚拟机网卡。
用管理员终端指定手机能访问的局域网 IP：

```powershell
& "$env:LOCALAPPDATA\Programs\wows_coyote\wows_coyote.exe" --transport v3 --advertise-ip 192.168.1.10
```

把 IP 换成电脑在手机同一网段的地址。

### 6.4 设置通道上限（第一次务必做）

**通道上限是 App 允许输出的最高强度，不是当前输出。**

第一次使用请先在 App 内把 A/B 两边都调低（例如 20–40，越保守越好）。
wows_coyote 没有软件强度上限设置，实际输出以 App/设备上报的上限为准。
确认体感没问题后再逐步提高。

## 7. 第一次安全测试

### 7.1 先测设备，不开游戏（可选但推荐）

先把 Mod/游戏放到一边，只验证设备链路：

1. 关闭正在运行的 wows_coyote；
2. 打开终端，进入安装目录：

```powershell
cd "$env:LOCALAPPDATA\Programs\wows_coyote"
.\wows_coyote.exe --test-sequence
```

3. App 扫码绑定后，程序会自动跑一段约 17 秒的固定序列：
   基础 → 起火 → 受击 → 第二次受击（应只待播一次）→ 灭火 → 阵亡 → 结束；
4. 全程用低通道上限；随时按 **F12** 急停。

如果不方便用命令行，也可以跳过这一步，直接做下面的完整测试。

### 7.2 完整测试（游戏 + Mod + 设备）

1. 确认 Mod 已安装，且游戏里能写出 `wows_telemetry.jsonl`；
2. App 内把 A/B 通道上限调低；
3. 启动 wows_coyote，确认：
   - 设备已连接；
   - 控制台 A/B 为 0% 或接近 0%；
   - 遥测状态不是“等待文件”；
4. 进训练房；
5. 观察控制台：
   - 血量/战局状态开始更新；
   - 基础事件出现低强度输出；
   - 受击/起火/进水/阵亡时，事件流和 A/B 有变化；
6. 按 **F12** 或点控制台“急停”：
   - 输出应立即归零；
   - 确认 App/设备停止输出；
   - 需要恢复时点“重新武装”；
7. 测试关闭行为：
   - 关闭主窗口 = clear + 强度 0 + 退出程序；
   - 最小化主窗口 = 继续输出；
   - 关闭悬浮窗 = 只关悬浮窗，不归零。

如果强度太强：降低 **App 内的通道上限**，不要在游戏里硬扛。
如果完全没输出：先看第 9 节。

### 7.3 安全要点

- 电极按 DG-LAB 说明放置，**不要跨胸/颈部**；
- 第一次从低强度开始，A/B 分开测试；
- 皮肤发红、刺痛或任何不适时立即 F12/App 停止；
- 不要在使用中睡觉、驾驶或无人看管；
- 本程序不是医疗设备。

## 8. 正常使用流程

每次玩游戏建议按这个顺序：

1. 启动游戏（Mod 随游戏加载）；
2. 打开设备/App，确认设备已连上 App；
3. 启动 wows_coyote；
4. 确认设备已连接、遥测不是“等待文件”；
5. 进战斗；
6. 结束后关闭主窗口（归零退出），或继续下一局。

其他说明：

- 设置保存到 `%LOCALAPPDATA%\wows_coyote\settings.json`；
- 日志在 `%LOCALAPPDATA%\wows_coyote\logs\standalone.log`；
- 事件参数在“事件”标签页，第一次建议保持默认；
- OBS/悬浮窗在“输出窗口”卡片，可按需开启；
- standalone 与 DGHub 插件不要同时向同一设备输出。

## 9. 常见问题

### 9.1 Mod 没加载

- 游戏大更新后没有重跑 `install.bat`；
- `bin\<版本>\res_mods\PnFModsLoader.py` 被删；
- 安装时没有写 `res_mods` 权限（用管理员重跑）；
- 检查 `<游戏根>\profile\python.log` 是否有
  `[ExportShipStatus] Created instance`；
- 确认安装到了当前游戏实际使用的 `bin\<版本>` 目录。

### 9.2 遥测文件没有数据

- 还没进战斗：文件只在对局中存在，退出对局后会被清空；
- 路径选错：重新选 `profile` 目录或游戏根目录；
- Mod 没加载：先看 `python.log`；
- 游戏更新后 Mod 缺失：重跑 `install.bat`；
- 文件存在但为空：确认是训练房/实战，不是港口。

### 9.3 V4 连不上

- 手机是否能上网（官方 Relay 需要互联网）；
- App 是否是 DG-LAB 4 App 4.x，是否进入 Socket 控制；
- 二维码是否过期：点“保存并刷新”或重启程序；
- 官方 Relay 不可用时，改“本机中继（local）”，手机和电脑同局域网；
- 检查本机防火墙/代理/VPN。

### 9.4 V3 连不上

- 手机和电脑是否同一局域网；
- Windows 防火墙是否允许专用网络；
- 路由器是否开启 AP 隔离；
- 多网卡/VPN 时二维码地址可能不对，使用 `--advertise-ip`；
- 端口是否被占用：换一个端口或重启程序；
- 扫码后 App 是否显示绑定成功。

### 9.5 已连接但没输出

- App 通道上限是否为 0；
- 是否处于急停状态（控制台“输出已急停”）；
- 基础事件是否启用、通道是否选对；
- 遥测是否真的在读（控制台血量/战局状态是否变化）；
- 是否把 A/B 都设成了 0；
- 是否同时运行了 DGHub 插件在抢输出。

### 9.6 强度太强/太弱

- 强度上限以 App/设备上报为准，先调 App 的通道上限；
- 软件没有独立强度上限设置；
- 第一次建议 20–40，甚至更低；
- A/B 分开调，不要一次拉满。

### 9.7 F12 没反应

- 其他软件占用了 F12（录屏/截图/游戏覆盖层）；
- 用控制台“急停”按钮；
- 用 `--hotkey F11` 等其他键启动；
- 关闭主窗口也会归零。

### 9.8 SmartScreen / 安装失败

- 安装包未做代码签名，SmartScreen 可能提示；
- 先用 `Get-FileHash` 核对 `.sha256`，一致再选“仍要运行”；
- 安装路径有中文/空格一般没问题；
- 杀毒软件拦截时，确认文件来源和哈希后再放行。

### 9.9 WebView2 缺失

- 主窗口打不开时，安装 Microsoft Edge WebView2 Runtime；
- 或临时用浏览器模式：

```powershell
& "$env:LOCALAPPDATA\Programs\wows_coyote\wows_coyote.exe" --browser
```

### 9.10 更新检查失败

- 0.1.0 没有更新检查代码，必须手动安装 0.1.1 一次；
- 0.1.1 自动检查有 24 小时间隔，手动“检查更新”不受限制；
- 网络/代理/防火墙可能拦截清单地址；
- 检查失败只记日志，不影响配对、遥测和输出。

清单地址：

```text
https://wowsdg-update.woyiba.com/wows_coyote/latest.json
```

## 10. 更新

0.1.1 起：

- 启动约 10 秒后检查一次，之后每 24 小时一次；
- 设置页“更新”卡片和控制台顶部横幅会提示新版本；
- 只提示，不自动下载、不自动安装；
- 点“前往 GitHub 下载”打开 Release 页面；
- 可以“跳过此版本”，也可以取消跳过；
- 网络失败只记日志，不影响游戏输出。

升级步骤：

1. 先关闭 wows_coyote 主窗口（确保 clear + 归零）；
2. 从 GitHub Release 下载新安装包并核对 SHA256；
3. 运行安装包覆盖安装；
4. 启动新版；设置和日志不会丢失。

0.1.0 用户没有检查代码，需要手动安装一次 0.1.1，之后才会收到应用内提示。

## 11. 卸载与回滚

### 11.1 卸载 wows_coyote

Windows 设置 → 应用 → 已安装的应用 → `wows_coyote` → 卸载。

卸载不会删除：

```text
%LOCALAPPDATA%\wows_coyote\settings.json
%LOCALAPPDATA%\wows_coyote\logs\
```

需要彻底清理时手动删除 `%LOCALAPPDATA%\wows_coyote`。

### 11.2 卸载 Mod

```bat
uninstall.bat
```

或显式指定游戏根目录：

```bat
uninstall.bat "D:\Games\World_of_Warships"
```

### 11.3 回滚版本

下载上一版 Release，关闭程序后覆盖安装。降级前建议备份：

```text
%LOCALAPPDATA%\wows_coyote\settings.json
```

新旧版本配置键可能不完全兼容。
