## 1. 定稿结构

采用 **pywebview 主窗口（控制台 / 设置 / 事件标签页）+ 置顶悬浮窗**；没有 pywebview 时整体回退浏览器：

| 界面 | 入口 | 职责 |
|---|---|---|
| 控制台 `/` | 主窗口「控制台」标签 | A/B 强度、战局、当前效果、事件流、急停 |
| 设置 `/settings` | 主窗口「设置」标签 | 设备/QR / App 通道上限、OBS 浏览器源、数据源 |
| 事件 `/events` | 主窗口「事件」标签 | 基础/受击/起火/进水/死亡、函数表、波形/曲线预览 |
| overlay `/overlay` | 主控制台「悬浮窗」按钮或 `run.py --overlay` | 连接/急停状态、A/B 圆形仪表（数字居中）、HP/战局、停/恢复/关闭 |

关键约束：

- 整体使用黑黄（暗金 `#c9a400` + 近黑）配色，深色为默认；可切换亮色主题；
  仅急停/断开等危险状态用少量红色；
- 急停必须在主控制台顶栏和 overlay 上都可达；
- **全局 F12 急停**（可配置/禁用）；
- 不设首次设置向导：启动直接进主控制台；配对/遥测在设置标签完成；
- 不向用户暴露 owner/模板 id、五类贡献表、遥测 offset/坏行等内部细节；
- 输出关闭（急停/未连接）时 A/B 归零显示，避免“已急停但仍显示强度”的误读；
- 安全要点放在主控制台底部的可展开「安全使用」，不再用向导拦截；
- 控制台/设置/事件是同一窗口内的标签页，不再另开设置窗口；切换标签不归零；
- overlay 置顶显示；窗口模式下与主程序同进程，浏览器模式下独立小窗；
- 不做波形编辑器；模板只读，仅在事件卡的下拉框里以名称出现。

### 窗口与关闭行为

| 操作 | 行为 |
|---|---|
| 主窗口 X / Alt+F4 | 立即 clear + 强度 0 + 静音 → 关闭悬浮窗 → 停 F12/UI/设备 → 退出；不做二次确认 |
| 控制台 / 设置 / 事件标签切换 | 同一窗口内切换，不归零、不退出 |
| 设置页「退出程序」 | 归零并退出；浏览器回退模式用它退出进程 |
| 悬浮窗关闭 | 只关闭悬浮窗，不归零，主程序继续 |
| 最小化主窗口 | 不归零，继续输出 |
| 浏览器回退模式 | 关闭/刷新标签页 `ui_close` 归零，但 Python 进程继续；Ctrl+C 退出 |
| 强制结束/崩溃/断电 | 无法保证归零指令送达，需在 App/设备侧确认 |

主窗口是程序生命周期：pywebview 的 `closing` 事件触发 Python 归零，而不是只依赖页面 `pagehide`。
在 pywebview 主窗口中刷新页面或切换标签不会触发急停；关闭窗口才会归零并退出。

## 2. 主控制台

```text
+ wows_coyote ------------------------------ [悬浮窗][急停] +
| ● 已连接                                                     |
+-------------------------------------------------------------+
| 控制台 | 设置                                               |
+-------------------------------------------------------------+
| A  起火                                       44.8%         |
| =============--------------------------------                |
| B  进水                                       44.8%         |
| =============--------------------------------                |
+-------------------------------------------------------------+
| 战斗中                                   HP 83.9%           |
| ● 起火 ×2   ● 进水 ×1                          [输出归零]   |
+-------------------------------------------------------------+
| 最近事件                                                    |
| 23:12:32  A · 进水                                          |
| 23:12:36  UI 急停：已归零                                   |
+-------------------------------------------------------------+
| F12 全局急停 · 关闭窗口会自动归零                            |
+-------------------------------------------------------------+
```

- 顶栏：连接/急停状态 + 悬浮窗、急停；下方标签栏「控制台 / 设置 / 事件」，急停始终可见。
- 强度卡：A/B 百分比、进度条、当前效果（基础/受击/起火/进水/死亡/静默）。
- 战局卡：战斗状态、HP、起火/进水标签、输出归零；找不到遥测时给出「设置遥测」入口。
- 事件流：最近 6 条，中文事件名 + 强度变化；不显示 owner/模板 id。
- 急停后显示黄黑警示条，A/B 归零；点「恢复输出」重新武装。
- 底部「安全使用」可展开：电极不跨胸/颈部/头部、合格导电片、首次低强度、不适立即 F12/App 停止。
- 不展示五类贡献表、遥测 offset/坏行、模板来源/版本等内部信息。

## 3. 设置页（主窗口标签页）

```text
+ wows_coyote / 设置 ---------------- [保存设置] [退出程序] +
| 控制台 | 设置 | 事件                                     |
| 设备：连接方式 V4/V3 · Relay 官方/本机 / App 通道上限 / 二维码 |
| 输出窗口：OBS（开关/端口/背景不透明度/地址/复制）          |
|           · 悬浮窗（整体不透明度）  [双列]                 |
| 遥测文件：路径 + 浏览；高级（读取间隔/静默超时）折叠        |
+----------------------------------------------------------+
```

- 设置标签只放设备/输出/遥测，不再混入事件参数；切换标签不归零。
- 设备卡顶部选择连接方式（默认 V4，可切 V3）和 V4 Relay
  （官方/本机中继），保存后自动切换并刷新二维码；命令行参数优先。
  二维码旁提供「保存并刷新」按钮：保存设置并强制刷新二维码。
- OBS 与悬浮窗合并为「输出窗口」双列卡片；详细模式只在卡片头统一说明
  “额外显示当前触发事件”，端口/透明度不再写默认值和额外解释。
- 首次必选项只有「遥测文件」；配对每次启动在设备卡扫码；
  强度上限以 App/设备通道上限为准，不再有软件强度上限设置。
- 设备卡按传输方式显示不同文案：
  - V3：连接郊狼 App，手机和电脑需在同一局域网；
  - V4 本机中继：连接 DG-LAB 4 App，手机和电脑需在同一局域网；
  - V4 远程 Relay：连接 DG-LAB 4 App，不要求同一局域网；
  - 同时显示当前连接方式、App 数量和设备名。
- 设备卡的 A/B 通道上限来自手机 App（V3：绑定反馈；V4：intensityMax），
  文案说明它表示 App 内允许的最高强度，不是当前输出，
  实际输出以该上限为准。
- 遥测路径可选 `.jsonl` 文件，也可只选到 `profile` 文件夹或游戏根目录，自动查找
  `wows_telemetry.jsonl`；设置页说明 `profile` 在游戏根目录下，例如
  `D:\SteamLibrary\steamapps\common\World of Warships\profile`。
- OBS 浏览器源在「输出窗口」左列：开关、端口、背景不透明度、复制地址；
  透明度只影响 OBS 卡片背景。
- 悬浮窗在同一卡片右列：整体不透明度通过 Windows 分层窗口作用于整个悬浮窗。
- 悬浮窗和 OBS 源各有「详细模式」开关；页面统一说明为“额外显示当前触发事件”。
  实现上追加基础/受击/起火/进水/死亡与贡献强度，固定顺序原地更新，
  HP 始终保留，基础事件有贡献时常驻。
- 设置保存后实时应用，并写入 `%LOCALAPPDATA%\wows_coyote\settings.json`。
- 战斗中修改事件参数/模板/通道即时生效，不结束战局；
  更换遥测路径会结束当前战局并重新接入，切换连接方式会断开当前 App，
  静默超时会结束本局；这些提示在设置页显示。
- 高级「读取间隔」控制 standalone 轮询遥测文件的频率。
- QR 由 `/qr.svg` 提供；手机 App 使用 Socket 控制扫码
  （V3 用郊狼 App，V4 用 DG-LAB 4 App；二维码随 V4 targetId 刷新）。

### 主题切换

- 控制台/设置/事件顶栏右侧有太阳/月亮按钮：深色时点太阳切亮色，亮色时点月亮切深色；
- 主题即时保存到 `%LOCALAPPDATA%\wows_coyote\settings.json` 的 `theme`（`dark`/`light`），
  不依赖只在本页面有效的 localStorage；
- 服务端按已保存主题在 HTML 首帧注入 `data-theme`，重启程序或切换标签不会先闪深色；
- pywebview 主窗口的原生标题栏同步切换（Windows 11 颜色属性；旧系统退回系统默认）；
- overlay 与 OBS `/obs` 跟随同一主题；OBS 页面仍保持透明背景；
- 亮色主题使用暖白底 + 深金强调文字，进度条/波形柱仍用亮金填充，避免小字号对比不足。

## 3.1 事件标签页

```text
+ wows_coyote / 事件 ---------------- [保存设置] [退出程序] +
| 控制台 | 设置 | 事件                                     |
| 基础 / 受击 / 起火 / 进水 / 死亡                          |
| 配置方案：下拉 + 读取/删除/导出；名称 + 保存/导入          |
| 启用 · 强度 / 通道 / 波形（高级参数折叠）                  |
| 波形条状预览；函数表路径 + 当前曲线预览                    |
+----------------------------------------------------------+
```

- 五类事件从设置页拆出，避免设置页过长；切换标签不归零。
- 事件页顶部「配置方案」：命名保存/读取/删除五类事件参数，
  并支持导入/导出 JSON；方案放在
  `%LOCALAPPDATA%\wows_coyote\event_presets\`，与设备/遥测设置分离；
  「保存为方案」只写方案文件，「读取」立即应用并保存到 `settings.json`。
- 基础/受击的高级参数会显示当前函数表路径，并允许选择自定义
  `base.json` / `hit.json`；留空回到随包默认，浏览默认打开函数表所在程序目录。
- 波形下拉下方有 DGHub 风格条状预览：柱高=强度，竖向条密度=频率；
  函数表高级区显示当前曲线折线预览，未勾选「使用函数表」时隐藏预览。
- 曲线预览带简单坐标轴：基础横轴为血量 100%→0%（左高右低），
  受击横轴为损失 0%→100%；横轴、纵轴均标注 0/50/100% 数值，
  图下方有“横轴/纵轴”说明，纵轴为强度 0–100%。
- 受击的触发阈值/满强度放在普通参数区；高级参数只保留函数表配置。
- 可改：五类事件的启用、强度/阈值/时长/通道/模板；高级参数默认折叠。
- 任一事件当前贡献强度为 0 时不选择波形；已播放的波形会在贡献归零时 clear。
  基础/受击的函数表返回 0 与线性强度配置为 0 都按此处理。
- 模板下拉只显示名称，不显示 id/source/license。
- 事件设置保存后实时应用，并写入 `%LOCALAPPDATA%\wows_coyote\settings.json`。

## 4. overlay（置顶小窗）

```text
+--------------------------------------------+
| ● 已连接  战斗中         🔒 ⚙   关闭       |
|        ╭───────╮      ╭───────╮            |
|        │   A   │      │   B   │            |
|        │  45%  │      │  62%  │            |
|        │ 45/100│      │ 93/150│            |
|        ╰───────╯      ╰───────╯            |
| HP 83.9%                  [恢复] [急停]    |
+--------------------------------------------+
```

- 默认 400×240；可置顶。
- 窗口模式：与主窗口同进程的第二 pywebview 窗口；`--overlay` 启动时直接打开。
- 浏览器模式：`run.py --overlay` 调用 `standalone/overlay.py` 独立小窗。
- 顶部「关闭」或 Esc：只关闭悬浮窗，不归零，主程序继续。
- 详细模式（可选）：在仪表下方增加当前事件行；只显示仍在贡献强度的事件，
  使用固定顺序和原地更新，不展示事件日志；HP 常驻底部。
- A/B 仪表圆心显示百分比，下方显示实际强度/通道上限（如 `45% 45/100`）：
  V3 使用已下发的原始强度，V4 使用 App 回报的 `current`；断连/急停显示 0。
- 停 = 急停（clear + 强度 0 + muted）：状态点/边框变红，A/B 归零；恢复 = 重新武装。
- 卡片铺满窗口并 `overflow:hidden`，不出现滚动条。
- Windows/WebView2 的 `transparent` 会露白/黑底；实际用圆角窗口区域裁剪，
  视觉上只剩卡片、没有矩形背景。
- 整体不透明度 30–100（默认 100）：通过 Windows 分层窗口让桌面/游戏透出；
  降低时文字、仪表和按钮一起变淡，低于 30 会明显影响可读性，因此不开放。
- 锁定（鼠标穿透）：顶部 🔒 按钮、设置页开关或全局 END 热键切换；锁定后
  悬浮窗不再接收鼠标点击/拖动，直接落到游戏；状态点旁显示 🔒，解锁后恢复。
- 不显示 owner/模板等细节，只保留连接状态、A/B、HP/战局。

### OBS 浏览器源

- 设置页新增「OBS 浏览器源」卡片：启用开关、端口（默认 8787）、运行状态、可复制地址；
- 保存后启动独立只读服务，不复用主 UI 的随机端口；
- `/obs` 复用悬浮窗页面，但在 OBS 模式下：
  - 页面背景透明，卡片四周留透明边距；
  - 卡片背景不透明度 20–100（默认 86），只改背景 alpha，文字保持清晰；
  - 隐藏关闭、设置、停、恢复按钮，不提供交互；
  - `overflow:hidden`，无滚动条；轮询与悬浮窗一致。
- OBS 添加 `http://127.0.0.1:8787/obs`（端口可在设置页修改），
  源尺寸建议 400×240。
- 端口被占用时设置页显示错误；关闭开关即停止 OBS 服务。
- 应用未运行或 OBS 源未刷新时可能显示空白；启动应用后刷新源即可。
