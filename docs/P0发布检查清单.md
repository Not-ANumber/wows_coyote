# P0 发布检查清单

> 目标：普通用户无 Python 环境安装、扫码、游戏、急停、卸载。
> 对应 standalone 1.0.0。
>
> 当前（2026-11-23）：1.0.0 发布版本；`tools/audit_release.py` 为
> `FAIL 0 / REVIEW 0`（含源码包敏感性/基础设施人工复核）；
> 10 局/干净 Windows 待验收。

## 0. 发布前审计（每次必跑）

```bash
py -3.13 tools/make_release.py
py -3.13 tools/audit_release.py
```

- [ ] 审计输出 `FAIL 0 / REVIEW 0`；
- [ ] 发布集与 `build_standalone_zip.collect_entries()` 一致；
- [ ] 三个发布物都不含 `qr.svg`、`*.log`、`settings.json`、`*.pyc`；
- [ ] 不含开发机路径/用户名、token/私钥、真实配对 ID；
- [ ] 源码包不含内部部署运维文档、服务器绝对路径、其他项目名称/宿主环境信息；
- [ ] `SHA256SUMS.txt` 与各 `.sha256` 均与实际文件一致；
- [ ] `releases/latest.json` 的 version/size/sha256 与实际安装包一致。

完整流程见 [`standalone发布指南.md`](standalone发布指南.md)；更新清单的
服务器部署细节见仓库维护文档（不随源码包分发）。

## 2. 干净 Windows

- [ ] Win10/11 x64，无 Python、无开发环境；当前机器可用
  [`docs/本地标准用户干净环境测试.md`](本地标准用户干净环境测试.md)
  （或 [`docs/VirtualBox干净环境测试.md`](VirtualBox干净环境测试.md)）；
- [ ] 从安装包安装，默认最低权限，不需要管理员；
- [ ] 开始菜单/桌面快捷方式直接打开桌面主窗口；
- [ ] 首次启动直接进入主控制台（无 `/setup` 向导）；
- [ ] 设置页「遥测文件」可指定/浏览；每次启动重新扫码配对；
- [ ] 设备卡说明 App A/B 通道上限的含义（不是当前输出）；
- [ ] 遥测卡说明 profile 位于游戏根目录；可只选到 profile 目录，能自动找到 wows_telemetry.jsonl；
- [ ] 受击触发阈值/满强度在普通参数区；不使用函数表时不显示曲线预览；
- [ ] 基础/受击高级参数显示函数表路径，可改选自定义 base.json/hit.json；
- [ ] 任一事件强度为 0 时不输出波形；基础/受击函数表为 0 和线性强度为 0 都不触发波形；
- [ ] 波形下拉下方有 DGHub 风格条状预览；函数表高级区有曲线预览；
- [ ] 曲线预览横轴为：基础血量 100%→0%（左高右低）、受击损失 0%→100%；
- [ ] 曲线预览的横轴和纵轴都有 0/50/100% 数值标注；
- [ ] 函数表“浏览…”默认打开函数表所在程序目录；
- [ ] 主控制台底部「安全使用」可展开，F12 急停可用；
- [ ] 关闭主窗口 = 归零并退出（无二次确认）；
- [ ] 控制台/设置/事件标签切换不归零；关闭悬浮窗只关窗口、不归零；
- [ ] 顶栏太阳/月亮按钮可切换亮/暗主题；重启后保留，overlay/OBS 跟随；
- [ ] 设置页可开关 OBS 源、改端口（默认 8787）、看到运行状态并复制地址；
- [ ] OBS 背景不透明度（默认 86）和悬浮窗整体不透明度（默认 100）保存后生效、重启保留；
- [ ] 悬浮窗/OBS 详细模式可独立开关；开启后显示当前事件与贡献强度，不滚动、不刷屏；
- [ ] 详细模式下 HP 始终可见，基础事件有贡献时常驻；
- [ ] 悬浮窗 A/B 显示实际强度/通道上限，V3/V4 都能更新，断连/急停归零；
- [ ] 降低悬浮窗透明度后桌面/游戏能透出，文字/按钮一起变淡；降低 OBS 透明度时文字仍清晰；
- [ ] `/obs` 透明、只读、无滚动条；关闭开关后端口不可访问；
- [ ] 最小化主窗口继续输出；重新武装可用；
- [ ] 设置页改遥测路径/事件参数后重启仍保留；
- [ ] 中文/空格安装路径正常；
- [ ] 防火墙弹窗/专用网络提示可处理；
- [ ] 卸载后程序目录移除，`%LOCALAPPDATA%\wows_coyote` 用户设置和日志保留（可选手动清理）。

## 3. 真机

- [ ] `--test-sequence` 17 秒序列通过；
- [ ] 10 局完整游戏：无崩溃、无意外输出；
- [ ] base/fire/flood loop 不断档；
- [ ] clear 后无明显尾音/旧 pulse；
- [ ] 受击连续触发只 pending，不堆队列；
- [ ] 死亡后归零；
- [ ] 手机锁屏/切 Wi-Fi/重连后先归零再恢复；
- [ ] V4 目标变化后 1–2 秒内主动探测校验；一次只发一条增量，确认后才算下一条；
- [ ] V4 同一个旧上报值不连续补正向增量，丢失增量能通过归零锚定恢复；
- [ ] V4 上报高于目标时只向下修正；目标 0 只归零；
- [ ] V4 完整快照缺 `intensity` / `hasDevice=false` / `isMuted` 时不继续补差值；
- [ ] V4 归零确认不了时进入安全锁定，不恢复非零输出；
- [ ] V4 已确认后手动调低被接受，手动调高高于目标会向下修正；
- [ ] V4 冷启动 `warmUpScale < 1` 时不回正、不归零、不采用缩放值；
- [ ] 切换/选中 V4 设备时先归零再重发当前强度，旧设备无残留输出；
- [ ] App feedback-0 / 急停 / 重新武装；
- [ ] 记录 App 版本、A/B 上限、clear 尾音、重连耗时。
