# 当前机器上的干净环境安装测试

> 当前机器：Windows 11/10 Home（Build 26200），x64。
> Home 版不提供 Windows Sandbox / Hyper-V；本机也未装 VirtualBox/VMware。
> 因此推荐 **“新建标准本地用户”** 做安装/首次启动/无 Python 测试；
> 如果要“全新 Windows”，用 VirtualBox/VMware 建 VM。

---

## 0. 先构建安装包

### 0.1 构建 exe / 便携包

```bash
py -3.13 -m pip install pyinstaller
py -3.13 tools/build_windows.py
```

确认：

```text
dist/wows_coyote/wows_coyote.exe
dist/wows_coyote/_internal/...
releases/wows_coyote-1.0.0-gpl.zip
releases/wows_coyote-1.0.0-win64.zip
```

### 0.2 安装 Inno Setup 并编译

```powershell
winget install --id JRSoftware.InnoSetup -e
```

或从 <https://jrsoftware.org/isdl.php> 安装。

命令行编译：

```bat
cd /d <项目目录>
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\wows_coyote.iss
```

输出：

```text
dist_installer\wows_coyote-1.0.0-setup.exe
```

中文语言文件已随仓库放在 `installer/ChineseSimplified.isl`，不需要额外复制到 Inno 安装目录。
安装向导可选择简体中文。

## 1. 推荐方案：新建标准本地用户（当前 Home 版可用）

完整步骤见 [`docs/本地标准用户干净环境测试.md`](本地标准用户干净环境测试.md)；下面是摘要。

优点：不装 VM、不管理员安装、全新用户配置、手机与电脑仍在同一局域网。
缺点：不是全新 Windows；系统级运行库/驱动仍共享。

### 1.1 创建测试用户

管理员 PowerShell：

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File tools\create_clean_test_user.ps1
```

脚本会：

- 创建标准本地用户 `wows_clean`（默认不在 Administrators）；
- 生成临时密码并打印；
- 不创建管理员权限。

然后 **注销当前用户**，用 `wows_clean` 登录。

### 1.2 确认“干净”

在该用户的 PowerShell：

```powershell
whoami
echo $env:LOCALAPPDATA
Get-Command python,py -ErrorAction SilentlyContinue
Test-Path "$env:LOCALAPPDATA\wows_coyote\settings.json"
```

预期：

- `%LOCALAPPDATA%` 是 `C:\Users\wows_clean\AppData\Local`；
- 没有来自开发机用户目录的 Python；
- `settings.json` 不存在（首次启动）。

> WindowsApps 里可能有 `python.exe` 商店别名，或机器级 `msys64` Python；
> 它们不代表 exe 依赖 Python。要严格证明，用最小 PATH 启动 exe：
> ```powershell
> $env:PATH = "$env:SystemRoot\system32;$env:SystemRoot"
> & "$env:LOCALAPPDATA\Programs\wows_coyote\wows_coyote.exe" --no-ui --no-telemetry --port 0
> ```
> 能启动即说明运行时不依赖 Python。

### 1.3 安装

把安装包复制到测试用户桌面（或直接从项目的 `dist_installer\` 目录运行）：

```text
wows_coyote-1.0.0-setup.exe
```

检查：

- 不弹 UAC（`PrivilegesRequired=lowest`）；
- 安装到：
  ```text
  C:\Users\wows_clean\AppData\Local\Programs\wows_coyote
  ```
- 中文安装向导可切换；
- 许可页显示 GPL-3.0；
- 安装目录包含：
  ```text
  LICENSE
  THIRD_PARTY.md
  SOURCE_OFFER.md
  CHANGELOG.md
  source\wows_coyote-1.0.0-gpl.zip
  wows_coyote.exe
  _internal\...
  ```

### 1.4 首次启动

- 开始菜单/桌面快捷方式启动；
- 直接进入主控制台（不再有 `/setup` 向导）；
- 设置页「遥测文件」指定/浏览遥测路径；每次启动在设置页重新扫码配对；
- 主控制台底部「安全使用」可展开；强度上限以 App/设备通道上限为准；
- 手机与电脑同一局域网，App 使用 Socket 控制扫码；
- 防火墙弹窗：允许专用网络；标准用户可能无法点“允许”，需要管理员预先加规则或临时用管理员登录放行；
- 检查：
  ```text
  C:\Users\wows_clean\AppData\Local\wows_coyote\settings.json
  C:\Users\wows_clean\AppData\Local\wows_coyote\qr.svg
  ```

### 1.5 功能验收

- F12 全局急停；
- 关闭主窗口归零并退出；控制台/设置/事件标签切换不归零；关闭悬浮窗只关窗口、不归零；
- 设置页改遥测路径/事件参数后重启仍保留；
- 设备扫码、A/B 输出、clear、loop；
- 卸载后程序目录删除，`settings.json` 保留（可选手动清理）。

### 1.6 卸载与清理

设置 → 应用 → 已安装的应用 → `wows_coyote` → 卸载。

注销测试用户，回到管理员 PowerShell：

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File tools\remove_clean_test_user.ps1
```

这会删除 `wows_clean` 用户和 `C:\Users\wows_clean` 配置目录。

## 2. 更干净：VirtualBox / VMware 虚拟机

当前机器未安装虚拟化软件；如果要做“全新 Windows”，完整步骤见
[`docs/VirtualBox干净环境测试.md`](VirtualBox干净环境测试.md)。概要：

1. 安装 VirtualBox（或 VMware Workstation Player）；
2. 准备 Windows 10/11 x64 ISO；
3. 新建 VM，网络选 **桥接网卡**（手机才能访问 VM 的 WebSocket 服务）；
4. 安装 Windows，创建本地用户；
5. 不要安装 Python/开发工具；
6. 把安装包通过共享文件夹/ISO 放进 VM；
7. 安装 → 首次启动 → 扫码 → 游戏/测试序列 → 卸载；
8. 测试前拍快照，测试后回滚。

注意：

- 桥接模式下 VM IP 与手机同网段；NAT 模式下手机通常连不上；
- Windows 11 VM 需要 vTPM/Secure Boot，VirtualBox 支持 vTPM；
- 安装包不需要管理员，但桥接网络/防火墙策略可能需要。

## 3. Windows Sandbox（仅 Pro/Enterprise/Education）

当前 Home 版不可用。若在支持的系统上：

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -All
```

重启后创建 `.wsb`，把 `dist_installer` 映射为只读，登录后运行安装包。
Sandbox 每次都是全新配置，适合安装/首次启动；但 NAT 网络可能无法让手机访问，设备配对建议在新用户/VM 桥接下测。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 安装时提示 Source 文件不存在 | 先运行 `tools/build_windows.py` |
| Inno 编译找不到中文语言文件 | 确认 `installer/ChineseSimplified.isl` 存在；.iss 已引用本地文件 |
| 测试用户 `where python` 有结果 | 可能是 WindowsApps 商店别名/机器级 msys64；用最小 PATH 启动 exe 验证 |
| 手机连不上 | 检查同一局域网、访客隔离、防火墙、`--advertise-ip`；VM 用桥接 |
| 标准用户无法放行防火墙 | 管理员登录后为 exe 添加专用网络规则，再切回测试用户 |
| 卸载后设置还在 | 有意的；删除 `%LOCALAPPDATA%\wows_coyote` 彻底清理 |
